# EstatePrime — Real Estate Discovery Platform

[![EstatePrime homepage](https://raw.githubusercontent.com/Kelvinkingly/Kelvinkingly/main/assets/estateprime-homepage.jpg)](https://estateprime-knowedge.infinityfreeapp.com/)

[Visit live website](https://estateprime-knowedge.infinityfreeapp.com/)

An independent WordPress portfolio platform by KnowEdge Business Development Services Ltd, featuring editable property records, responsive property catalogue, location/type/price/bedroom filters, browser-local shortlist, illustrative mortgage amortisation calculator, image gallery and local viewing enquiry preview.

No real property offers, loans, transactions or personal data collection are provided. Listings and images are illustrative.

## Installation

Zip the `theme/estateprime` folder and upload through WordPress Appearance → Themes. Activate it to seed initial property records. Use the Properties section in WordPress to edit content and custom fields.
